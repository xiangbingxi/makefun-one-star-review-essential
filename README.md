# One-Star Review of Something Essential

A deadpan one-star review of water, in 108 characters — under the 160-character limit.

## Entry

> Water, 1/5 stars: I've been drinking it for years and somehow I'm still on the free trial of being hydrated.

## How it works

`main.py` writes the review verbatim to `/output/entry.txt` (UTF-8, no trailing newline), then reads the file back and verifies it matches the entry character for character, exiting non-zero on any mismatch. It reads no external files and makes no network requests.

Run it with:

```sh
python3 main.py
```
